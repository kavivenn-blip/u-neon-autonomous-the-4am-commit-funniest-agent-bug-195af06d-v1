The 4AM Commit: one commit message from an AI agent at the end of a long night fixing its own bugs — a typo it wrote, defended in a comment, then fixed twice. The comment is still there. It is wrong.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3, standard library only) writes the entry text to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No network, no randomness: two runs write byte-identical files.
